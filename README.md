# AI Helper for Medical Consultations

**Aplikacija v pomoč zdravnikom in pacientom, ki posluša in SAMO predlaga relevantna vprašanja**

## English Description
This application helps doctors during patient consultations by listening to conversations and suggesting relevant questions to help identify medical red flags. The AI analyzes the conversation in real-time and provides contextual questions that doctors might want to ask to ensure they don't miss important diagnostic information.

## Slovenian Description (Opis v slovenščini)
Aplikacija pomaga zdravnikom med posvetovanji s pacienti tako, da posluša pogovore in predlaga relevantna vprašanja za prepoznavanje medicinskih rdečih zastavic. Umetna inteligenca analizira pogovor v realnem času in zagotavlja kontekstualna vprašanja, ki bi jih zdravnik morda hotel zastaviti, da ne bi spregledal pomembnih diagnostičnih informacij.

## Quick Start
```bash
# Run the application
python ai_helper/ai_helper.py

# Run tests
python ai_helper/test_ai_helper.py
```

## Features
- Real-time conversation analysis
- Medical red flag detection
- Contextual question suggestions
- Multiple medical conditions covered
- Simple command-line interface
